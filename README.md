# Elevator Controller System

## About the Project
A C# Windows Forms application developed for the Desktop Application Development and Software Engineering assignment (CIS0116-2) at the University of Bedfordshire.

## Features
- Graphical user interface for elevator control
- Floor selection and request handling
- Elevator movement animation
- Database logging using Microsoft Access
- Object-oriented programming principles
- State and Observer Design Patterns
- Two-elevator system (where implemented)

## Technologies
- C#
- Windows Forms
- Microsoft Visual Studio
- Microsoft Access Database
- .NET Framework
